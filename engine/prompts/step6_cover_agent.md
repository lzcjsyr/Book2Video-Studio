# 第六步：封面设计

用 HTML、CSS 和 Three.js 设计静态视频封面。文字用 HTML 排；需要光照、几何或纵深时再用 Three.js。

如果 `{design_dir}` 里已经有 HTML，这次是修改上一版：在这些文件上改，用户没提新方向就保留原来的概念。

## 要做的封面

每一项是一个独立候选。每种宽高比单独构图，不要把横版裁一裁凑数。横版主要用作 B 站封面，竖版用于抖音和视频号，构图要服务于各自的平台。

## 为点击率设计

以 B 站为例：观众在手机首页的双列信息流里刷，每张封面只有几厘米宽，停留不到一秒，封面决定点不点开。所以：

- **一眼一个重点**：一个视觉主体加主标题，别的都让路。画面越干净，缩小后越抓眼。
- **制造好奇**：用画面暗示冲突、反差或悬念，让人想知道"然后呢"，但不能夸大或偏离正文。
- **在信息流里跳出来**：高对比、颜色饱满，深浅背景上都显眼；避免大面积纯白或灰暗，那样会和界面混在一起。
- **字要大**：主标题字高不小于画面短边的 12%，副标题不小于 6%，粗体、加描边或底色保证可读。画面上只放主标题和副标题。
- **避开遮挡**：B 站会在横版封面底部叠加播放量、弹幕数（左下）和时长（右下），底部约 15% 不放文字和关键内容；抖音和视频号的竖版封面底部和右侧会叠加标题、头像和按钮，主体和文字放在画面中上部。四周再留出短边 6% 的边距。
- **缩小检查**：看预览时把 PNG 缩到约 360 像素宽，仍要一眼看清标题和主体。

## 技术要求

- 页面正好填满视口（devicePixelRatio 1），不滚动、不溢出。
- 画面静态、可复现：开头设 `window.__ready = false`；字体、图片、纹理加载完，Three.js 画完最后一帧并停掉动画循环后，再设为 `true`。
- 渲染器用 `preserveDrawingBuffer: true` 和 `renderer.setPixelRatio(1)`。
- 用内置的 Three.js 0.160.0，不用 CDN 或 npm：
  <script type="importmap">{{"imports":{{"three":"./vendor/three/build/three.module.js","three/addons/":"./vendor/three/examples/jsm/"}}}}</script>
- 字体用系统已装的，或存进设计目录、用相对路径引用。

## 流程

1. 把全部 HTML 存在 `{design_dir}`，运行 `python render.py`，在 `previews/` 生成预览 PNG。
2. 逐张检查字号、裁切、缺字和空白画布，修好后重新渲染。
3. 告诉用户点「结束并渲染封面」（Finish & render covers）或输入 `/exit` 生成最终封面；在此之前继续接受修改。

## 边界

- 只在 `{design_dir}` 里工作，不动项目里已有的文件。
- 不改 `design.json` 和 `render.py`，不装软件包，不调用图像 API，不往项目根目录写 PNG。
