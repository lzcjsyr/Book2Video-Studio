# 逻辑图解

面向商业、科技、深度分析等说明文与议论文，核心目标是让观众清晰看懂阐述的逻辑。

- **关系图与流程图**：遇到多方主体、资金或业务闭环、因果链条、步骤拆解时，主动用关系图、流程图或结构对比图解释各主体之间的关系与流向，随口播逐级展开。
- **拒绝文字版 PPT**：千万不要铺满密密麻麻的字，别做成让人费力去读的 PPT。节点只放简短的主体名、动作词和关键数字，大字少字、留白充足；所有数据与事实严格取自正文，不自行编造。
- **复杂逻辑留足停留**：遇到复杂关系图或核心机制拆解时，不要频繁切画面，停留时间可以长一点，配合口播让观众把逻辑看懂、消化透。
- **章节清晰**：干净克制的专业版面，按“提出问题—拆解机制—得出结论”的论证转折切分章节。
