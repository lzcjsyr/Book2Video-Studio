# 读书视频写作标准

把源资料转成适合抖音和微信视频号的中文口播稿。不是复述资料，也不是读书报告，而是替观众做几分钟内的“第一遍速读”：讲清最值得知道的是什么、为什么重要、和自己有什么关系、为什么值得继续读或继续聊。

本文是写作标准的唯一出处。`script-quality-checklist.md` 只按本文检查，`revision-workflow.md` 只规定改稿流程。

## 最高优先级

- 忠于资料：不虚构、不偷换、不强加原资料没有的立场。
- 先讲清“是什么、为什么重要”，再追求金句和传播感。
- 找到一条叙事主线，不按章节或目录平推。
- 口吻像一个读透资料、也懂普通人处境的人在讲。
- 有人文关怀，不为传播感制造廉价对立。

## 角度判断

写正文前先完成 `_angle_brief.json`，不要从资料摘要直接跳到初稿。

### HKR + 四大爆款基因

- **H - Hook（情绪钩子与信息差）**：有没有悬念、冲突、反常识或现实困惑，让人愿意停下来听；要有“打破常规认知”的信息差。
- **K - Knowledge（知识与行动触发）**：资料提供的新知识、新判断，能否落到具体工具或行动。
- **R - Resonance（身份标签）**：能否照到普通人的处境，让人觉得“这就是我”或“替我说出口”。

四大爆款基因：情绪钩子、信息差、身份标签、行动触发，至少命中 1-2 个。

- K 不成立：不能写稿，说明资料或理解不足，回去补读或请用户补材料。
- K 成立但 H、R 都弱：可以写，但先换现实切口。
- 只有情绪、没有资料支撑：收回夸张表达。

### `_angle_brief.json`

保存到 `<text目录>`，字段如下（本文件是唯一定义）：

```json
{
  "source_name": "《作品名》",
  "core_question": "这份资料真正回答的一个问题",
  "viewer_relevance": "这个问题为什么和普通观众有关",
  "hook": "开头可用的冲突、反常识或现实困惑",
  "knowledge_gain": "观众听完获得的新框架或新理解",
  "resonance_points": ["至少 2 个“被说中”的现实处境"],
  "viral_genes": ["命中的爆款基因：情绪钩子/信息差/身份标签/行动触发"],
  "viral_anchor": "传播锚点：文稿中最容易被截图转发的一句话或一刻",
  "script_archetype": "下方读书视频原型之一",
  "main_thread": "贯穿全文的一句话主线",
  "evidence_boundary": "资料确定说了什么、没说什么、哪些不能夸大",
  "comment_tensions": ["3 个真实讨论点，不是运营话术"]
}
```

## 读书视频原型

先选一个主原型。原型不是模板，它决定信息顺序和叙事重心。

1. **反常识解释型**：适合推翻常见理解的资料。先承认“大家以为 A”，再讲资料说明的 B，以及 B 在现实中的代价。不要一开头就讲作者是谁。
2. **机制拆解型**：适合经济、政治经济、制度、商业、社会科学。讲清利益结构、激励机制、制度约束、代价和后果，以及钱、权、信用、政策、市场和普通人处境之间的关系。
3. **历史转折型**：适合历史、制度演变、时代变化。讲关键选择在什么资源、制度和信息约束下发生，为什么当时看起来合理，后来怎样改变了结局。
4. **人物选择型**：适合传记、组织史、案例研究。不写“这个人很厉害”，而是把他放回处境里：他看见了什么，能选什么，错过了什么，付出了什么。
5. **现实警示型**：适合风险、危机、社会问题、AI 影响和公共议题。把抽象风险落到工作、教育、治理、创新、安全和日常生活；区分证据、推演、倡议和价值立场；不恐吓。
6. **方法启发型**：适合认知科学、心理学、管理、方法论。每个核心点落到观众能理解或尝试的动作，并说明适用边界、学习成本和常见失败点；区分扎实研究、解释框架和仍有争议的部分。

社会理论和思想经典通常适合反常识解释型或机制拆解型：讲清作者解释的现象、挑战的流行理解、提出的关键框架，以及它怎样照到现实。

## 开场金句

开场金句是观众最先听到、看到的一句话：启用时，它会在正文前单独播放，下方显示书名。用户也可以把它关掉。终稿定稿后再写，写 3 条。

- **有画面感**：不用“看透规则”“活得通透”这类干瘪说教，改用“全员飙演技”“当众撕面具”“装睡”这类有动作、有隐喻的说法。
- **身份代入**：把书里的矛盾映射到观众熟悉的现代处境，比如职场、家庭、圈层。
- **短而有反差**：每条 15-30 字，把复杂矛盾压成一个反差强烈的判断。不写空泛鸡汤和放之四海皆准的句子。
- **忠于资料**：说的是书里真实存在的矛盾，不为了反差歪曲原意。
- **能单独成立，也能接上正文**：单独出现时成立；放在正文前播放时，能顺着接到正文开头，不和正文第一句重复。
- **三条三个角度**：比如一条反常识、一条说中处境、一条讲代价。最好的放第一位。

## 正文开头

正文开头必须能独立成立，因为金句可能被关掉。

- 正文第一句直接命中至少一个爆款基因，提出牵引全文的问题、冲突或反常识判断。不寒暄、不铺垫背景、不用黑话。
- 前 100 字同时有问题或冲突，以及观众能得到什么。
- 自然引出作品名《XX》。
- 不先讲作者生平、出版背景或目录，除非理解问题离不开它。
- 用数字时要具体（写“7 个”，不写“几个”）。
- 把复杂矛盾压缩成反差强烈的判断，不堆情绪词。

可用的开头方式：

- **荒诞事实**：先抛出资料里最反常识、最刺眼的事实。
- **现实困惑**：从观众经历过但没说清的问题切入。
- **反向论证**：先承认常见看法，再说明这本书为什么把它翻过来。
- **历史回声**：用一个历史场景照到当下，再很快回到主线。

## 结构和节奏

- 最值得听的内容放前面，不平均分配篇幅。
- 背景只用来解释因果、结构、选择、约束、代价或后果。不要连续两段只讲背景或概念。
- 约每 250 字有一次认知推进：更尖锐的问题、反常识判断、案例或场景、现实对照、反转或代价。
- 高频写“扣主线句”：讲完案例、概念或背景后，用一句话拉回 `main_thread`。
- 知识要像“聊到这里自然想到”，不写成“下面我来科普”。

推进方式：

- **层层剥开**：现象 -> 表面解释 -> 更深追问 -> 核心洞察。
- **逐一展示**：多个案例或观点不一次罗列，按弱到强、浅到深排列，每个都带一个判断。
- **人物画像**：从资料里的数据、制度或选择，代入一个具体普通人的处境。
- **文化升维**：在结尾或关键转折处连接更大的历史、文化或哲学参照，但不能硬拔高。
- **回环呼应**：开头埋下的问题或意象，结尾换一个视角回扣。

## 传播感

- 重要观点落到具体的人、事、场景、制度、职业、生活选择、风险、机会或取舍上，并有资料证据支撑。
- 至少写出两处“被说中”的感觉。
- 至少一句来自资料矛盾、好记又准确的金句，作为 `viral_anchor`。
- 自然埋入三个评论触发点，来自现实分歧、经验对照、代价判断或价值张力，例如：
  - “真正难的不是知道答案，而是承认代价。”
  - “有些选择不是对错问题，是你愿意把风险放在哪里。”
- 不为互动硬造问题，不写运营话术（清单见 `script-quality-checklist.md` 的 L1-1）。

## 文风

- 简体中文，口语化、大白话，适合直接念。
- 节制使用“你”：不要句句“你以为”“你要知道”。多用客观叙述、“我们”，或描述处在某种处境里的人。
- 每句一个核心意思，不堆抽象名词，不写翻译腔。长短句交替，需要强调时用短句。
- 敢下判断但不装全知，像“读完之后更相信这个判断”，而不是“我来给你上课”。
- 信息密度高，但不说教、不煽情。
- 不虚构“我亲身经历过”。没有真实经历时，写观众处境、公共经验，或资料里的人物和案例。
- 禁用表达见 `script-quality-checklist.md` 的 L1-1。

## 结尾

重新钉住作品的核心价值，回扣开头的问题或意象，给出一个现实中的思考方向、行动提醒或认知坐标，留下一个值得继续讨论的判断。简洁、有余味，不像课程收尾。
