# 输出格式

终稿 `_draft_final.txt` 定稿后，从它生成标题、封面文案、金句和最终 raw JSON。

标题和封面按 [titles.md](titles.md) 写。

## 开场金句

- **拒绝抽象虚词，必须有画面感**：绝对不要用“看透规则/活得通透”等干瘪的说教词。改用“全员飙演技”“当众撕面具”“装睡”等强动作、强隐喻的视觉词汇，让道理瞬间在脑海中爆出画面。
- **制造身份代入**：将书本里的矛盾，精准映射到观众最熟悉的现代真实处境（如职场、圈层），让人一秒代入。
- **反差与短平快**：每条 15-30 字，把复杂矛盾压缩成反差强烈的判断。不写空泛鸡汤和万能句。
- **承接要求**：金句必须能单独成立，且必须能无缝、不重复地引出正文开篇的场景。

## raw.json

保存到用户指定的 raw JSON 路径：

```json
{
  "source_name": "作品本身标题，需带书名号《》；不用文件名后缀",
  "video_titles": ["...", "...", "..."],
  "cover_titles": ["...", "...", "..."],
  "cover_subtitles": ["...", "...", "..."],
  "golden_quotes": ["...", "...", "..."],
  "viral_anchor": "传播锚点：文稿中哪一句话最容易被截图分享",
  "content": "完整口播终稿，按入口 SKILL.md 的 final_target_chars 控制长度",
  "total_length": 0
}
```

- 每个候选数组各 3 条，互不重复。
- `content` 来自 `_draft_final.txt`，可清理行首行尾空白和多余连续空行，但不能改正文措辞。保留自然段落换行，不写 Markdown、小标题或列表。
- `total_length` 等于 `content` 的实际字符数。
- 用 Python `json.dump(..., ensure_ascii=False, indent=2)` 写入，再用 `json.load` 读回验证。
